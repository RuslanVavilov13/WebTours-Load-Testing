
# Нагрузочное тестирование WebTours

Учебный проект по нагрузочному тестированию веб-приложения WebTours с использованием Apache JMeter 5.6.3.

## Реализованные сценарии

### 1. Регистрация пользователя
- Создание нового пользователя.
- Генерация уникального логина и пароля.
- Проверка успешности регистрации.

### 2. Авторизация пользователя
- Чтение тестовых пользователей из CSV-файла.
- Извлечение динамического параметра `userSession`.
- Авторизация и проверка успешного входа.

### 3. Бронирование авиабилетов
- Авторизация пользователя.
- Случайный выбор города отправления и прибытия.
- Генерация дат путешествия.
- Случайный выбор типа места и предпочтений по размещению.
- Проверка успешного бронирования.

## Используемые инструменты

- Apache JMeter 5.6.3
- Git
- GitHub
- WebTours

## Особенности проекта

- Параметризация тестовых данных.
- Корреляция динамических значений.
- Использование CSV Data Set Config.
- Проверки HTTP-ответов.
- Использование Module Controller.

## Примечание

Файл `users.csv` с тестовыми учётными данными не публикуется в репозитории. Для выполнения сценариев, использующих CSV, необходимо предварительно создать этот файл.
